# Tuition Finder

A Dhaka home-tuition marketplace where families find local tutors and guardians post tuition requirements.

Live demo: https://nafiz-xd.github.io/tuition-finder/

## Features

- Tutor listings with real photos, subjects, classes, Dhaka area, experience, schedule and expected monthly salary in ৳
- Filter listings by subject, class and area, all at once
- Live search across tutor name, subject, area and university
- "Post a Tuition" form — new posts are saved to localStorage and appear at the top of the list instantly
- One-tap Call Now button on every card using a `tel:` link
- Warm amber marketplace design with big rounded cards, hover lift and staggered fade-in entrance animations
- Fully responsive, works from `file://` and GitHub Pages with no build step

## Tech Used

- HTML5
- CSS3 (grid, flexbox, keyframe animations)
- Vanilla JavaScript
- localStorage for posted tuitions
- Tutor/teaching photos from Wikimedia Commons (stored locally in `images/`)
